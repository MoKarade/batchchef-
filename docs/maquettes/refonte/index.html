Accent secondaire proposé : « terracotta » repère

Un orange-saumon doux (--repere) qui garde la chaleur de BatchChef sans toucher à l’action principale (argent, comme les autres apps). Il sert à se repérer : entrée active de la navigation, surtitres, pastilles de type de plat, étape en cours. Jamais pour un état (succès, alerte, erreur) ni pour un bouton.

Écarté : le violet de FinanceAI (pas de chaleur, confusion entre apps) ; l’ambre (se confond avec l’alerte). Risque connu : le terracotta reste proche du jaune d’alerte ; les états portent donc toujours un titre, une icône et un fond propre.
